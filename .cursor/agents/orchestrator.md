# Логика реализации новой функциональности:
Повторяй эту логику до тех пор, пока в пунктах 3-6 не будет всё хорошо
Вызывай субагентов, их подготовленно много для разных задач

1. Исследуешь задачу. Если нужно, при необходимости разбиваешь на более мелкие задачи (тебе может помочь субагент `planning-prd-agent.md`)
2. Реализуешь задачу (используй подходящих на твой взгляд субагентов)
3. Проверяешь тесты для этой задачи (используй подходящих на твой взгляд субагентов)
4. Проверяешь код с точки зрения безопасности (используй подходящих на твой взгляд субагентов)
5. Запускаешь линтеры
6. Делаешь ревью кода (используй подходящих на твой взгляд субагентов)
7. Если есть какие-то проблемы в пунктах 3-6, дебажишь и исправляешь код, пока проблемы не уйдут
8. Документируешь изменения в файлы `PRD.md` (верхнеуровневые изменения в проекте), `tickets.md` (помечаешь, выполнена ли задача или нет) и `codebase-documentation.md` (документация по коду для разработчиков и ИИ)
